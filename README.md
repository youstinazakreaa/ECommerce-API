# E-Commerce API

A RESTful E-Commerce Web API built using ASP.NET Core following Onion Architecture principles.

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Redis
- ASP.NET Core Identity
- JWT Authentication
- AutoMapper
- Swagger

## Architecture

The solution is divided into multiple layers:

- Core Layer
- Repository Layer
- Services Layer
- API Layer

This separation helps keep the project organized and maintainable.

## Features

- Product Management
- Product Brands and Types
- Filtering and Searching
- Sorting
- Pagination
- Generic Repository Pattern
- Specification Pattern
- DTOs and AutoMapper
- User Registration
- User Login
- JWT Authentication
- Redis Shopping Basket
- Global Error Handling
- Swagger API Documentation

## API Endpoints

The API currently includes endpoints for:

- Products
- Accounts
- Shopping Basket

## Project Status

The project is currently under development.

Planned features include:

- Delivery Methods
- Checkout
- Payment Integration
